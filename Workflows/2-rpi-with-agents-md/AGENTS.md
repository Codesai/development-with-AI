# Feature workflow

1. Research relevant .NET and browser code before editing, identify existing ASP.NET Core patterns and explain them briefly.
2. Explore more than one option to approach the implementation, present to user and wait for approval.
3. Write a short plan and wait for approval.
4. Keep changes within the requested feature.
5. Add focused automated validation.
6. Run `make validate`.
7. Report changed files and exact results.

Never weaken validation to make it pass.
